# INDUORA · Перемещение 1,5 кг между складами

Оператор переносит товар из одного склада в другой. Я связал форму на React с серверной командой проведения: документ и две проводки попадают в общий складской журнал одной транзакцией. Остатки, которые видит оператор после проведения, рассчитываются по этому журналу.

| Что сделал оператор | Склад-отправитель | Склад-получатель | Что видно в системе |
|---|---:|---:|---|
| Открыл черновик на 1,5 кг | 10 кг | 0 кг | Черновик ещё можно менять |
| Нажал «Провести» | 8,5 кг | 1,5 кг | Документ проведён. В журнале расход и приход по одной операции |
| Отменил проведение | 10 кг | 0 кг | Добавлены обратные проводки. Документ снова можно редактировать |

### Как связан интерфейс с остатками

Форма передаёт в API документ, ожидаемую ревизию и ID операции. Сервер проверяет права, текущее состояние документа и доступный остаток. Количество проходит через API десятичной строкой. Для арифметики оно приводится к целому с фиксированным масштабом через BigInt. Если запись проводок срывается, транзакция откатывает и изменение документа.

### Два сбоя с разными действиями для оператора

**На складе не хватило товара.** Сервер возвращает HTTP 409. Новых движений в журнале нет. Форма оставляет черновик открытым, оператор исправляет количество и отправляет его повторно.

**Во время проведения оборвался POST.** Вкладка сохранила исходную команду. Кнопка «Повторить исходную операцию» отправляет прежнее содержимое с прежним ID. Если сервер уже провёл документ от имени этого пользователя, повтор возвращает записанный результат. В журнале остаётся одна пара проводок.

### Откуда взяты результаты

Остатки и состояния формы взяты из локальной браузерной приёмки на учебных данных в сборках .58 и .59. В этой приёмке отдельно проверены отказ по остатку, компенсация и обрыв POST. 25 ноября 2026 года на исходниках повторно прошли 10 тестов документа, черновика и складской политики. Среди них конкурирующее проведение, повтор команды после обновления вкладки и откат записей при сбое внутри транзакции. Данные заказчика и исходники продукта здесь не публикуются.
