# Студент сменил группу, старая вкладка осталась открытой

Пользователь состоит в двух группах. После переключения старая форма всё ещё отправляет задание в первую. При записи проверяются и активная группа, и членство. Тест читает таблицу до и после отказа, затем повторяет сохранение из актуальной формы.

Из корня репозитория:

```console
python studygram/demo.py
```

Это автономная модель правила из Mini App. В ней нет Telegram, данных студентов и исходников рабочего бота.
