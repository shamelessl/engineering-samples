# Можно ли восстанавливать настройки потока после сбоя

Числа PID и TID в журнале совпали с текущими. Так бывает и после повторного использования идентификатора. Сравниваются времена создания процесса и потока, затем проверяется, успела ли программа подтвердить исходную операцию. Тесты показывают, когда восстановление следует пропустить.

Из корня репозитория:

```console
python windows/demo.py
```

Разбираются синтетические записи журнала. Скрипт не меняет состояние ОС.
