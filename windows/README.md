# Можно ли восстанавливать настройки потока после сбоя

[Пример на C#](ProcessIdentity.cs) читает время создания собственного процесса через GetProcessTimes и сверяет его с временем из System.Diagnostics.Process. В Windows с компилятором .NET Framework: `csc ProcessIdentity.cs`, затем `.\ProcessIdentity.exe`. Совпадение проверяется в коде и отражается в коде завершения. Следующий Python-тест моделирует альтернативные истории PID/TID и потерю подтверждения. Запуск C# не меняет состояние процессов и не собирает ETW-трассу.

Числа PID и TID в журнале совпали с текущими. Так бывает и после повторного использования идентификатора. Сравниваются времена создания процесса и потока, затем проверяется, успела ли программа подтвердить исходную операцию. Тесты показывают, когда восстановление следует пропустить.

Из корня репозитория:

```console
python windows/demo.py
```

Разбираются синтетические записи журнала. Скрипт не меняет состояние ОС.
