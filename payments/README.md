# Банк не ответил после списания

В этом примере шлюз принимает платёж, а ответ теряется. Воркер запрашивает статус по прежней ссылке операции. Проверь запись в журнале и событие outbox после позднего ответа. Смена суммы под тем же ключом должна вызвать конфликт.

Из корня репозитория:

```console
python payments/01_idempotency_and_reconcile_demo.py
```

[Контракт API и действия дежурного](01_api_spec_and_runbook_sample.md). Шлюз здесь имитируется, рабочая БД и деньги не используются.
