# Сколько стоил товар в день продажи

| Вход утреннего среза | Проверяемое значение |
| --- | --- |
| Январская выручка после загрузки мартовских цен | 2 200 ₽ по цене на дату визита |
| Филиал 1, 10 марта | 5 800 ₽; девять строк этой пачки ушли в карантин |
| Филиал 3 прислал выгрузку в 12:05 при отсечке 07:00 | NULL, статус incomplete_source |

Первый и третий тесты проверяют эти числа запросом к представлению. Это воспроизводимая контрольная выборка, суммы в ней вымышленные.

Для продажи нужна цена на дату операции. Два действующих тарифа могут удвоить выручку при обычном JOIN. SQL отправляет спорные строки в карантин и помечает неполный отчёт, если к утреннему дедлайну не пришла выгрузка.

Из корня репозитория:

```console
python data/02_test_scd2_sql.py
```
