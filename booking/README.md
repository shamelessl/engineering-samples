# Слот изменился между предложением и подтверждением

Двум посетителям предложили одно время. Первый подтверждает запись, второй получает запрос обновить предложение. В другом сценарии перед подтверждением меняется цена. Один условный UPDATE сверяет цену и доступность; тест проверяет состояние слота после отказа.

Из корня репозитория:

```console
python booking/demo.py
```

Запросы воспроизводятся последовательно на SQLite. Сервис клиники, календарь врача и реальные записи отсутствуют.
