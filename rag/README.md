# Когда поиск нашёл нужный пункт, а ответ всё равно неверный

В регрессионном примере поиск вернул REG-101, а ответ звучал так: «Через 10 рабочих дней. Письменное заявление не требуется». Прежняя проверка принимала его из-за срока и правильной ссылки. Регламент требует заявление. Теперь этот ответ получает `HALLUCINATION_OR_BOUNDARY_ERROR`. Непроверенный пересказ, включая правильный по смыслу, уходит в `NEEDS_REVIEW`. Автоматический допуск в этом стенде есть только для полностью сверенной формулировки. Коммерческая контрольная выборка здесь не используется.

В наборе есть регламент с порогом строго больше 15 минут. Результат поиска и правильность ссылки проверяются отдельно. В тесте видно, как меняется вывод при промахе поиска, неверной ссылке и ложном утверждении в записанном ответе.

Из корня репозитория:

```console
python rag/03_rag_retrieval_vs_citation_eval.py
```

Набор фраз и ожидаемых ответов задан явно. Внешняя модель и векторная БД для запуска не нужны. Оценка относится только к этим фразам.
