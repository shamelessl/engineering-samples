# Инженерные примеры

Небольшие задачи, которые можно запустить и проверить. Для всех примеров нужны Python 3.10+ и стандартная библиотека. Исходные данные синтетические.

| Сценарий | Что посмотреть |
| --- | --- |
| [Банк не ответил после списания](payments/) | Платежи, сверка и журнал событий |
| [Сколько стоил товар в день продажи](data/) | Исторические цены и качество данных |
| [Две вкладки сохраняют одну карточку](forms/) | Параллельная запись и черновик при конфликте |
| [Получатель записал пачку, отправитель потерял подтверждение](crm/) | Повтор пачки и транзакция |
| [Когда поиск нашёл нужный пункт, а ответ всё равно неверный](rag/) | Поиск и проверка цитирования |
| [Почему лучший IoU может дать худшую границу](vision/) | Сегментация и метрики |
| [Слот изменился между предложением и подтверждением](booking/) | Серверная проверка действия ассистента |
| [Можно ли восстанавливать настройки потока после сбоя](windows/) | Журнал восстановления |
| [Что действительно наблюдалось в журнале IPC](ipc/) | Сопоставление контракта с наблюдениями |
| [Студент сменил группу, старая вкладка осталась открытой](studygram/) | Контекст и права при записи |

Запуск всего набора из корня:

```console
python check.py
```

У каждого примера есть отдельная команда и описание того, что проверяет тест.
