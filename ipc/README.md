# Что действительно наблюдалось в журнале IPC

[Разбор одного наблюдения с ожидаемым типом и результатом](contract-example.md). Есть конкретная ошибка потребителя и условие повторной проверки. Названия и журнал в примере вымышленные.

У тестового клиента три объявленных метода. Один вернул значение неожиданного типа, ещё один не встретился в журнале. Отчёт различает эти случаи и отдельно показывает вызов, отсутствующий в описании.

Из корня репозитория:

```console
python ipc/demo.py
```

В примере вымышленные методы и готовая трасса. Наблюдений за чужими приложениями или доступа к ним для запуска не требуется.
