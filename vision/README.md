# Почему лучший IoU может дать худшую границу

[Результаты эксперимента BEN2 на 98 кадрах](experiment.md): четыре режима, парные изменения IoU и Boundary F1, групповой бутстреп и решение оставить исходные веса. Ниже отдельный короткий пример на синтетических масках.

Первая маска покрывает половину квадрата, вторая захватывает квадрат целиком и добавляет кайму в один пиксель. У второй выше пересечение по площади, но весь внешний край смещён. Скрипт печатает обе пары метрик.

Из корня репозитория:

```console
python vision/demo.py
```

Это синтетические маски и точный Boundary F1 с нулевым допуском. Результаты не воспроизводят обучение BEN2 и замеры на фотографиях.
